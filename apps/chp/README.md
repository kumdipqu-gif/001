# chp

Fully local, portable Windows AI desktop application.

- No login, no cloud sync, no public AI endpoints.
- Runtime network guard only allows localhost / 127.0.0.1 / ::1.
- Local streaming chat via OpenAI-compatible local servers.
- Project workspace, file browsing/editing/search, local terminal and tasks.
- All persistent application data lives beside the executable under `data/`.
- Windows delivery is an unpacked portable directory compressed into split 7-Zip volumes; no installer is used.
